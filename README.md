# Climate Adaptation Strategies for Agricultural Use

## Overview
This project analyzes the relationship between soil health, crop yields, and climate data to generate data-driven climate adaptation strategies for agriculture. The goal is to support farmers and agricultural stakeholders in making informed decisions that improve productivity under changing climate conditions.

A predictive model was also developed and deployed through a simple Python application (`app.py`) to recommend suitable farming practices based on input environmental conditions.

## Problem Statement
Climate change has significantly affected agricultural productivity through changing rainfall patterns, soil degradation, and temperature variability. Farmers often lack data-driven tools to guide adaptive farming practices.

This project addresses that gap by:
- Analyzing agricultural and climate datasets
- Identifying patterns affecting crop yield
- Recommending suitable farming practices using predictive modeling

## Objectives
- Clean and analyze soil health, crop yield, and climate datasets
- Identify relationships between climate variables and agricultural output
- Build predictive insights for agricultural decision-making
- Develop a simple recommendation system using Python (`app.py`)


## Tools & Technologies
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook
- Flask


## Workflow
1. Data collection (soil, climate, crop yield datasets)
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature correlation and pattern identification
5. Model development for prediction/recommendation
6. Deployment using `app.py`

## Key Insights
- Soil health indicators strongly influence crop yield variability
- Climate factors such as rainfall and temperature significantly affect productivity
- Certain farming practices are more suitable under specific environmental conditions

## Application (`app.py`)
A simple application was developed to:
- Accept environmental inputs (soil, climate conditions)
- Predict likely agricultural outcomes
- Recommend suitable farming practices
